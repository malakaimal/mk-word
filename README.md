AK Word
=======

A lightweight browser document editor with rich text formatting, page sizes and orientation, tables, images, links, common mathematics symbols, a simple LaTeX helper, local autosave and PDF export through the browser print dialog.

GitHub Pages setup:
1. Open repository Settings, then Pages.
2. Choose Deploy from a branch.
3. Select main and /(root), then Save.
4. Visit https://malakaimal.github.io/mk-word/ after deployment.

Documents are stored locally in this browser and do not sync between devices. The LaTeX helper is lightweight, not a full TeX renderer.
